## Brand & Style

This design system establishes an architectural, ultra-clean aesthetic tailored for cloud infrastructure, file hosting, and secure data transmission. Drawing inspiration from modern high-throughput file services and enterprise storage platforms, the design fuses precision minimalism with high-tech tactile polish. 

### Target Audience & Personality
The experience serves digital professionals, creative agencies, software developers, and enterprise teams moving critical payload data across global networks. The interface exudes absolute security, velocity, and zero-clutter clarity. It communicates institutional trust without feeling bureaucratic, utilizing deep indigo-slate depths countered by luminescent emerald action cues that direct immediate user momentum.

### Visual Language & Movement
- **Precision Minimalism**: Strict spatial rhythm, clean structural separators, and immaculate whitespace eliminate file-transfer anxiety.
- **Modern High-Tech Tactility**: Softly elevated canvas containers, translucent floating bars, and hairline borders (0.5px to 1px) communicate engineered reliability.
- **Bilingual Fluidity**: First-class support for bidirectional layouts (LTR and RTL) ensuring equal hierarchy, legibility, and geometric balance whether rendering western or Arabic character systems.

## Colors

The palette leverages high-contrast functional color-coding to make state recognition instantaneous across intensive data views.

### Palette Architecture
- **Primary (`#1e293b` / Deep Slate-Indigo)**: Used for primary structural headers, high-emphasis navigation surfaces, critical text, and deep brand anchors. It provides grounded authority.
- **Secondary (`#059669` / Vivid Emerald)**: Reserved primarily for active positive transformations—prominently high-velocity download triggers, completed uploads, encrypted verification badges, and primary action states.
- **Tertiary (`#3b82f6` / Electric Cobalt)**: Drives active telemetry, processing indicators, share linkages, selection states, and interactive upload boundaries.
- **Neutral (`#64748b` / Slate Mist)**: Calibrates secondary body text, metadata timestamps, table borders, inactive pagination, and sub-labels.

### Background & Canvas Tones
- **Base Canvas**: `#f8fafc` (Ultra-light Slate) delivers soft luminosity without the glare of raw `#ffffff`.
- **Surface Elevation**: `#ffffff` (Pure White) defines floating transfer modules, table cards, and modaled drawers.
- **Hairline Dividers**: `#e2e8f0` provides razor-sharp boundary definition across table cells and toolbar groupings.

### Semantic & File Extension Tokens
- **PDF / Document**: `#e11d48` (Crimson) with tinted fill `#fff1f2`.
- **Archives (ZIP/TAR/RAR)**: `#d97706` (Amber) with tinted fill `#fffbeb`.
- **Media (MP4/MOV/WebM)**: `#8b5cf6` (Violet) with tinted fill `#f5f3ff`.
- **Code/Data (JSON/CSV/SQL)**: `#0284c7` (Sky) with tinted fill `#f0f9ff`.

## Typography

The typographical structure balances rapid scanning with dense metric legibility.

### Font Hierarchy & Pairing
- **Primary Typeface (Latin)**: **Plus Jakarta Sans** provides geometric crispness, open apertures, and modern tech authority without the generic neutrality of older system grotesques.
- **Primary Typeface (Arabic)**: Dynamically fallbacks to **Cairo** or **Tajawal** for Arabic locales (`dir="rtl"`). Cairo maintains the exact structural baseline, geometric counters, and optical density of Plus Jakarta Sans, preventing visual layout jumping during language switches.
- **Data & Telemetry**: **JetBrains Mono** is utilized strictly for checksums (SHA-256), cryptographic tokens, transfer speed rates (e.g., `48.2 MB/s`), and remaining time metrics.

### RTL Implementation Rules
- Headings and body copy inherit bidirectional typographic flow. 
- Font weights are normalized across scripts: Arabic letterforms in Cairo naturally display with slightly higher optical weight, so medium weights (`500`) are mapped directly to standard weights (`400`) in high-density Arabic tables to maintain vertical equilibrium.

## Layout & Spacing

The layout is built upon an adaptive 12-column fluid grid system pinned to a maximum canvas width of 1440px for cloud storage dashboards, collapsing gracefully into focused, singular viewports for dedicated transfer landing pages.

### Responsive Breakpoints & Reflow
- **Desktop (1024px+)**: 12-column layout. Sidebar navigation spans 280px fixed width, main data tables span the remaining columns. Standard margins of `2rem` (`32px`) and gutters of `1.5rem` (`24px`).
- **Tablet (768px – 1023px)**: 8-column layout. Sidebar collapses into an off-canvas slide-out or icon rail. File table simplifies columns, hiding secondary metadata (e.g., checksums, retention dates) behind detail modals.
- **Mobile (< 768px)**: 4-column layout. Layout switches from dense horizontal data tables to modular stacked card lists. Margin contracts to `1rem` (`16px`) and gutter drops to `0.75rem` (`12px`).

### Spatial Density
Spacing tokens prioritize compact data density (`space-xs` and `space-sm`) inside interactive lists and file trees, while allowing generous breathing room (`space-lg` and `space-xl`) around upload drop zones and transfer completion heroes.

## Elevation & Depth

This design system avoids heavy drop shadows in favor of ambient low-opacity occlusion combined with subtle surface borders.

### Elevation Levels
- **Level 0 (Flat/Base)**: `#f8fafc`. Background canvas.
- **Level 1 (Card/Surface)**: `#ffffff` paired with a hairline border (`1px solid #e2e8f0`) and an ambient shadow: `0 1px 3px rgba(15, 23, 42, 0.04), 0 1px 2px rgba(15, 23, 42, 0.02)`.
- **Level 2 (Dropdowns / Flyout Toolbars)**: `#ffffff` surrounded by `0 10px 15px -3px rgba(15, 23, 42, 0.08), 0 4px 6px -4px rgba(15, 23, 42, 0.03)` with `1px solid #cbd5e1`.
- **Level 3 (Upload Modals / Toast Alerts)**: High-altitude floating elements using `0 20px 25px -5px rgba(15, 23, 42, 0.1), 0 8px 10px -6px rgba(15, 23, 42, 0.04)`.

### Backdrop Blur (Glass Tier)
Floating action bars, sticky transfer status pills, and modal overlays use `backdrop-filter: blur(12px)` over an 85% alpha background (`rgba(255, 255, 255, 0.85)` in light mode, or `rgba(30, 41, 59, 0.85)` in dark containers) to ground elevated panels onto underlying file queues.

## Shapes

The design system adopts a refined, high-radius architecture (`roundedness: 2`, where base components utilize `0.5rem` and primary focal surfaces expand to `rounded-2xl` / `1rem` - `1.5rem`).

### Corner Geometry Tokens
- **Base Components (Inputs, Buttons, Badges)**: `0.5rem` (`8px`). Delivers tight, tool-like precision.
- **Interactive File Cards & Table Enclosures**: `1rem` (`16px`). Softens the enterprise data presentation into an accessible modern cloud interface.
- **Hero Transfer Modules (Drop Zones, Floating Download Cards)**: `1.5rem` (`24px`). Creates distinct visual containment for transient drag-and-drop operations.
- **Pills / Status Chips**: `9999px` (Full circle caps) for transfer rates, extension badges, and action pills.

## Components

### Buttons
- **Primary Download Trigger**: Emerald background (`#059669`), text `#ffffff`, hover state `#047857`, active scaling (`scale(0.98)`). Features an embedded downward arrow that transitions vertically on hover.
- **Secondary / Action**: Slate outline (`1px solid #e2e8f0`), text `#1e293b`, hover background `#f1f5f9`.
- **Ghost / Icon Button**: Borderless, padding `space-sm`, radius `0.5rem`, color `#64748b`, hover color `#1e293b` with background `#f1f5f9`.

### File Type Badges
- Structured as compact inline pills with micro-labels (`label-sm`, monospace or heavy sans):
  - **PDF**: Crimson text (`#e11d48`) on `#ffe4e6` fill.
  - **ZIP/Archive**: Amber text (`#b45309`) on `#fef3c7` fill.
  - **Media/Video**: Purple text (`#7c3aed`) on `#ede9fe` fill.
  - **Audio**: Cyan text (`#0e7490`) on `#cffafe` fill.
  - **Images**: Emerald text (`#047857`) on `#d1fae5` fill.

### Progress Bars
- **Track**: Height of `6px` (inline table) or `10px` (modal hero), background `#e2e8f0`, corner radius `9999px`.
- **Fill**: Linear gradient shifting from `#3b82f6` to `#059669` as progress reaches 100%. Animated shimmer effect during active data streaming.

### Data Tables
- Header cells: `label-md`, uppercase, color `#64748b`, border-bottom `1px solid #e2e8f0`, padding `0.75rem 1rem`.
- Row height: `56px`, hover background `#f8fafc`. Selected state applies `#eff6ff` fill and a `2px` left border (or right border in RTL) in `#3b82f6`.

### Copy-Link Notification & Floating Toasts
- Compact capsule positioned top-center or bottom-right.
- Dark Indigo pill (`#1e293b`) with white text, crisp checkmark in `#10b981`, and a subtle emerald pulse border. Auto-dismisses after 2400ms with a spring curve exit.

### Drag & Drop Zone
- Border: `2px dashed #cbd5e1`, changing to `2px dashed #3b82f6` on hover/dragover with a subtle background transition to `rgba(59, 130, 246, 0.04)`.
- Enclosure radius: `1.5rem` (`rounded-2xl`).

### RTL Component Mirroring
- Icon alignments, table column ordering (File Name -> Size -> Date -> Actions), and progress bar directions mirror seamlessly based on the `dir` attribute (`dir="rtl"` flows right-to-left). Action button chevrons invert 180 degrees automatically.
